Install APK

Tumia kitufe hapa chini kufungua ukurasa wa release au kupakua moja kwa moja APK. Ikiwa unataka kupakua/kuinstall moja kwa moja, badilisha thamani ya apkUrl kwenye sehemu ya script kwa link ya moja kwa moja ya faili ya APK (direct download link).

Fungua Release Page Pakua / Install (Direct)

Jinsi ya kupata direct APK link

  1. Fungua Release Page (kitufe cha juu).
  2. Bonyeza kulia juu ya asset (mfano: jina-la-faili.apk) kisha chagua "Copy link address".
  3. Badilisha thamani ya apkUrl hapa chini kwa link uliyokopi (au weka kama href ya #downloadBtn).

Maelekezo ya kuweka kwenye Android

  • Kurasa za Chrome/Edge zinaweza kuwezesha kupakua APK; baada ya kupakua fungua faili (tap) kwenye simu ili kuinstall.
  • Unaweza kuhitaji kuwezesha "Install unknown apps" kutoka kwa browser yako (Settings 16 Apps 16 Browser 16 Install unknown apps).
  • Kama browser haikuwezesha install moja kwa moja, pakua APK kisha ufungue kutoka kwa File Manager.

Usalama

Iliwezekane kupata onyo kwa sababu APK si kutoka Google Play. Hakikisha unamwamini muundaji kabla ya kuinstall.
